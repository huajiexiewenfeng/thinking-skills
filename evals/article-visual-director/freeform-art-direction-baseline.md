# Freeform Art Direction baseline

Date: 2026-09-14

An independent read-only agent inspected the pre-change Skill and was asked how it would add an article-level freeform mode. The control did not exhibit the feared conceptual failure: it recommended an article-scoped mode, no permanent golden, first-anchor approval, a frozen article-local contract, deterministic technical diagrams and typography, and non-authoritative visual references.

The observable product gap remained: the current resolver returned only ordinals 1–9 and the Skill had no dynamic-mode contract. Therefore the implementation adds the missing interface and validation shape without extra discipline language aimed at a failure the control did not show.

Baseline phrases included: “Style 10 应作为文章级定调模式接入，而不是第十个固定视觉 profile”, “也不应制作永久黄金图”, and “Style 10 只改变视觉语法，不改变现有安全边界”.
