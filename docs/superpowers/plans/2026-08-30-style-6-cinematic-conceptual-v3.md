# Style 6 Cinematic Conceptual v3 Implementation Plan

> **For agentic workers:** Execute sequentially because every later golden uses an earlier user-approved same-profile candidate as a non-semantic style reference.

**Goal:** Qualify `cinematic-conceptual` as a stable v3 style pack with three approved tactile-editorial goldens, cross-topic probes, and release validation.

**Architecture:** Add observable visual DNA, role-specific invariants, and same-role reference contracts around the existing Style 6 protocol. Approve cover, concept, and simplified metaphor-map assets sequentially, then qualify the pack through prompt compilation, neighbor discrimination, hashes, and release checks.

**Tech Stack:** JSON contracts, Markdown prompt records, Python `unittest`, `compile_image_prompt.py`, `validate_style_contract.py`, GPT Image generation, Git.

## Global Constraints

- Use a fully opaque deep navy environment based on `#10151D`.
- Use desaturated blue-slate distance layers, one matte mineral subject, and exactly one amber thesis cue based on `#E59A3A`.
- Use a restrained 50 mm cinematic perspective, one cool ambient fill, and one motivated warm practical light.
- Keep symbolic density very low: one coherent metaphor, not a collage of symbols.
- Use subtle atmosphere and low film grain without crushed blacks, spectacle, or decorative glow.
- Covers and concepts remain text-free; any later labels are deterministic overlays after semantic confirmation.
- Simplified metaphor maps are human-free and render only the validated frozen graph.
- No faces, lone people, fantasy cities, cosmic skies, neon portals, holograms, glass, chrome, product-ad reflections, isometric infrastructure, dashboards, or blueprint language.
- Every reference contract forbids copying `labels`, `numbers`, `nodes`, `topology`, and `example_story`.
