# Style 6 Cinematic Conceptual v3 Implementation Plan

> **For agentic workers:** Execute sequentially because every later golden uses an earlier user-approved same-profile candidate as a non-semantic style reference.

**Goal:** Qualify `cinematic-conceptual` as a stable v3 style pack with three approved cinematic narrative-landscape goldens, cross-topic probes, and release validation.

**Architecture:** Add observable landscape depth, journey, camera, human-scale, title-overlay, and same-role reference contracts around the existing Style 6 protocol. Approve cover, concept, and simplified landscape-map assets sequentially, then qualify the pack through prompt compilation, neighbor discrimination, hashes, and release checks.

**Tech Stack:** JSON contracts, Markdown prompt records, Python `unittest`, `compile_image_prompt.py`, `validate_style_contract.py`, GPT Image generation, Git.

## Global Constraints

- Use a fully opaque layered teal-blue valley or open landscape filling the frame.
- Use deep teal foreground, muted blue-gray distance layers, one pale journey line, and one golden horizon field.
- Use a restrained 35 mm elevated wide perspective with four readable depth bands and a stable horizon.
- Keep narrative density low: one winding journey, one horizon, and at most one small rear-view human figure.
- Use measured mist and restrained painterly realism without stock-travel polish, crushed blacks, spectacle, or decorative glow.
- Covers and concepts remain text-free; any later labels are deterministic overlays after semantic confirmation.
- Simplified metaphor maps are human-free and render only the validated frozen graph.
- No visible faces, front-facing people, crowds, multiple roads, multiple suns, fantasy cities, cosmic skies, neon portals, isometric infrastructure, dashboards, or blueprint language.
- Every reference contract forbids copying `labels`, `numbers`, `nodes`, `topology`, and `example_story`.
