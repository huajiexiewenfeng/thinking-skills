# Style 8 Golden Diagram Candidate Prompt — Human-free Architecture

Use case: pure architecture/process diagram and permanent Style 8 reference candidate.
Asset policy: no people, faces, hands, characters, instructors, mascots, portraits, or speech bubbles.
Topology: one large blue dashed boundary containing six numbered nodes in a single horizontal row: `Goal → Context → AI Plan → Tool Work → Verify → Output`. One small yellow dashed fallback group contains `Rework`. One coral dashed arrow goes from `Verify` to `Rework`; one black curved return arrow goes from `Rework` to `AI Plan`. No other nodes, arrows, or crossings.
Visual grammar: warm ivory textured paper, fine lively near-black handwritten ink, pastel-to-medium green/orange/blue rounded nodes, small technical icons, compact black section tabs for group headings only, slightly irregular direct arrows, flat marker fills, organized density, and a blank underlined conclusion zone.
Exact labels: `Primary Workflow`, `Goal`, `Context`, `AI Plan`, `Tool Work`, `Verify`, `Output`, `Fallback`, `Rework`.
Avoid: human imagery, descriptions, legends, extra prose, generic corporate vector styling, every-node black tabs, 3D/isometric, gradients, glass, photorealism, UI chrome, fake text, logos, and watermarks.
