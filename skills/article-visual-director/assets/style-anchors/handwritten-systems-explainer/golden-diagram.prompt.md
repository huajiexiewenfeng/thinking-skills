# Style 8 Golden Diagram Anchor — Style-only Architecture Reference

Reference role: permanent visual-style anchor for architecture and process diagrams.

This asset is approved for its visual expression only. Its example title, labels, node count, node order, arrows, fallback routes, boundaries, and conclusion are non-authoritative and must never be copied into a new article diagram unless independently supported by that article's frozen semantic graph.

Preserve from this anchor:

- warm ivory textured paper;
- fine lively near-black handwritten ink;
- dense but organized two-level architecture composition;
- numbered rounded nodes with compact non-human technical icons;
- blue and yellow dashed group boundaries;
- direct black primary arrows and restrained coral dashed exception paths;
- pastel-to-medium green, orange, and blue semantic fills;
- compact black section tabs used only for group headings;
- small handwritten annotations, legend treatment, and underlined conclusion rhythm;
- architecture/process diagrams contain no people, faces, hands, characters, instructors, or mascots.

Required production separation:

1. AI derives a new article-specific semantic graph from the current article and confirmed sources.
2. The graph records exact node labels, stable IDs, group membership, directed edges, edge types, invariants, and blocked relationships.
3. The graph is validated and frozen before rendering.
4. This golden image supplies only visual grammar; its sample content and topology are ignored.
5. The rendered artifact is compared edge-for-edge and node-for-node with the frozen graph. Any logical mismatch is rejected and corrected before publication.

Avoid: copying this example's wording or topology, invented relationships, human imagery, generic corporate vector styling, every-node black tabs, 3D/isometric treatment, gradients, glass, photorealism, UI chrome, fake text, logos, and watermarks.
